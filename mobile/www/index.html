HydroLoop Farm Manager

Cette application charge HydroLoop depuis le serveur sécurisé de l'exploitation.

La première ouverture nécessite une connexion Internet. Ensuite, les fonctions locales (batchs, relevés, journal de culture) restent disponibles hors ligne.

Si cette page s'affiche, le serveur n'a pas pu être joint : vérifiez la connexion puis relancez l'application.
