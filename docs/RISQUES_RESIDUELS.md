# Examen des risques résiduels

| Risque | Analyse | Décision / action | Statut |
|---|---|---|---|
| **CSP `unsafe-inline` (scripts)** | Nécessaire à l'amorçage Next.js sans nonce. Le reste de la CSP est strict (`default-src 'self'`, `connect-src` limité, `frame-ancestors 'none'`, `object-src 'none'`). Vérifié par recherche dans le code : aucun `dangerouslySetInnerHTML` ; le rendu Markdown du rapport est en JSX ; le seul `innerHTML` (étiquette QR) reçoit le SVG généré par la bibliothèque, l'identifiant du batch étant inséré via `textContent`. Un CSP à nonces impose le rendu dynamique de toutes les pages (perte du statique). | Acceptable pour la V1.0 ; passer aux nonces (middleware + `headers()`) en V1.1 si exposition publique forte. | Accepté, tracé |
| **Chiffrement local** | Les données IndexedDB sont lisibles par quiconque a accès au profil du navigateur déverrouillé. Chiffrer par mot de passe (WebCrypto) créerait un risque de **perte définitive** (mot de passe oublié) en contradiction avec la priorité « aucune donnée perdue », et compliquerait la synchro/hors ligne. | Ne pas chiffrer par défaut. Protection = verrouillage de l'appareil + chiffrement du stockage Android (activé par défaut) + déconnexion qui purge le cache des pages. Option V1.1 : export JSON chiffré. | Accepté, tracé |
| **Limitation de débit** | Limiteurs en mémoire par instance : en serverless multi-instances, les plafonds (connexion 5 essais, IA 6/10 min, 40/j/utilisateur, 400/j global) sont approximatifs. Le coût IA reste borné par instance ; la connexion est protégée en plus par le hachage scrypt. | Pour un hébergement multi-instances : magasin partagé (Upstash/Redis) ou règles WAF de l'hébergeur ; définir une limite de dépense au niveau du compte Anthropic. | À traiter avant exposition publique |
| **Branche `feat/varieties-modules-cycle`** | 2 commits (variétés, modules, cycle par variété, journal d'eau, module horizontal serre tunnel), 28 fichiers, +1323/−23 ; basée sur un état antérieur de `main` ; modifie `storage.ts`, `batch.ts`, `system-prompt.ts` **réécrits** par la V1.0 → conflits certains. | Ne pas fusionner telle quelle. Décision produit requise : abandon, ou reprise ciblée (variétés/modules) sur la base V1.0 avec migration du modèle de données et tests. | ⛔ Décision humaine |
| **Branche par défaut** | `claude/hydroloop-farm-management-IBF0C` est la branche par défaut mais retarde `main` de 2 commits. | Passer `main` en branche par défaut (Settings → Branches) et supprimer la branche obsolète après sauvegarde. | ⛔ Action humaine |
| **Branche `ccr-c075febe-kz7hym`** | Branche de session déjà fusionnée dans `main` (PR #1). | Supprimable. | Info |
| **Horloges des appareils** | Départage des champs en conflit par `updatedAt`. | Aucune perte de relevés/événements ; documenté. | Accepté |
| **Vulnérabilités `npm audit` (dev)** | 14 modérées, outillage ESLint (minimatch), non embarquées. | Surveillées en CI (seuil high en production). | Accepté |
